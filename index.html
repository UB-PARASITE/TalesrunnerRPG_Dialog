輸入 Dialog ID 後，這裡會顯示可操作的劇情路徑。

執行規則

  1. Set() 建立每組 Choice 的六槽索引。
  2. 槽位 0–4 是 ChoiceBranch1–5 的 Order。
  3. 槽位 5 是 ChoiceEnd 的 Order。
  4. _OnBranch(idx) 取得所選分支的起點。
  5. _OnNext() 播放所選內容，越過下一個分支邊界時跳至 ChoiceEnd + 1。

這是指定遊戲版本的靜態逆向分析結果；特殊巢狀流程仍待驗證。
